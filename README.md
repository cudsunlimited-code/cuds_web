# CUDS 홈페이지

중앙대학교 영어토론 동아리 **CUDS (Chung-Ang University Debate Society)** 공식 홈페이지

- 주소: https://cudsweb.vercel.app/

프레임워크나 빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 바로 볼 수 있습니다. 설치할 것은 없습니다.

## 배포 (Vercel)

GitHub 저장소가 Vercel 프로젝트에 연결되어 있습니다.

- `main` 브랜치에 push하면 Vercel이 자동으로 다시 배포합니다. 1분 안팎이면 https://cudsweb.vercel.app/ 에 반영됩니다.
- 빌드 과정이 없으므로 Vercel은 저장소 루트의 `index.html`을 그대로 서비스하고, `api/` 폴더의 파일은 서버리스 함수로 자동 배포합니다.
- 필요한 환경 변수 (Vercel 프로젝트 → Settings → Environment Variables)

| 이름 | 필수 | 설명 |
|---|---|---|
| `GOOGLE_API_KEY` | 필수 | Google Cloud API 키. 해당 프로젝트에서 **Google Calendar API**와 **Google Drive API**(갤러리용)를 둘 다 사용 설정하고, 키의 API 제한을 이 두 API로만 걸어 두는 것을 권장 |
| `GCAL_ID` | 선택 | 불러올 캘린더 ID. 생략하면 `cudsunlimited@gmail.com` |
| `GDRIVE_FOLDER_ID` | 선택 | 갤러리 사진을 읽을 구글 드라이브 폴더 ID. 생략하면 `Gallery` 폴더(`1ePToGxtANGVHkGJ0yWgnOw9D_vUTrS3o`) |

환경 변수를 추가하거나 바꾼 뒤에는 **다시 배포해야** 적용됩니다 (Deployments → 최근 배포 → Redeploy, 또는 새 커밋 push).

`index.html`을 파일로 바로 열면(`file://`) `/api/calendar`, `/api/gallery`를 부를 수 없으므로 달력은 내장 데이터(기본은 비어 있음)로만, 갤러리는 자리표시로만 표시됩니다.

`.nojekyll` 파일은 예전에 GitHub Pages로 배포하던 때 남은 파일입니다. Vercel에서는 쓰이지 않지만 두어도 문제는 없습니다.

```
│  └─ gallery.js       # Vercel 서버리스 함수: 구글 드라이브 폴더의 사진을 읽어 갤러리용 JSON으로 변환

```

## 달력 일정 (구글 캘린더)

일정 페이지(`#/calendar`)는 동아리 구글 캘린더 **`cudsunlimited@gmail.com`** 을 그대로 보여줍니다. 일정은 구글 캘린더에서 추가·수정하면 되고, 코드나 `index.html`을 고칠 필요가 없습니다.

동작 방식

1. 브라우저가 `/api/calendar`(`api/calendar.js`)를 부릅니다.
2. 이 함수가 Google Calendar API로 지난 1년 ~ 앞으로 1년의 일정을 읽어 사이트 형식으로 바꿔 돌려줍니다.
3. 결과는 Vercel에서 약 **10분간 캐시**됩니다. 구글 캘린더에서 고친 내용이 사이트에 보이기까지 최대 10분 정도 걸릴 수 있습니다.
4. API 키가 없거나 구글 쪽 오류가 나면 달력은 `index.html` 안의 `cal-data` 블록(아래 형식, 기본은 빈 배열)을 그대로 보여줍니다. 이 블록은 이제 **오프라인용 예비 데이터**일 뿐이며, 평소에는 고칠 필요가 없습니다.

**공개 범위 주의:** 이 캘린더에 공개로 올린 일정은 제목·장소·설명·첨부까지 모두 사이트에 그대로 표시됩니다. 사이트에 보이면 안 되는 일정은 구글 캘린더에서 공개 설정을 **비공개(Private)** 로 바꾸세요 (비공개 일정과 취소된 일정은 표시하지 않습니다).

### 일정 분류 (제목 앞 머리말)

일정 제목 맨 앞에 대괄호 머리말을 붙이면 색상·분류가 정해지고, 머리말은 사이트에 표시될 때 제목에서 빠집니다.

| 제목 예시 | 분류 | 색 |
|---|---|---|
| `[세션] 정기 세션 (BP)` | 세션 (`session`) | 파랑 |
| `[대회] KIDA 본선` | 대회 (`tour`) | 분홍 |
| `[행사] 개강총회` | 행사 (`event`) | 주황 |
| `[연합] 연합 세션` | 연합 (`joint`) | 초록 |
| `[기타] 시험 기간` | 기타 (`etc`) | 연보라 |

- 영문 머리말 `[session]` `[tour]` `[event]` `[joint]` `[etc]`도 됩니다 (대소문자 무관, `[ 세션 ]`처럼 공백이 있어도 됨).
- 머리말이 없거나 위 목록에 없는 머리말이면 **기타**로 분류되고 제목은 그대로 표시됩니다.

### 구글 캘린더 항목이 사이트에 표시되는 방식

| 구글 캘린더 | 사이트 |
|---|---|
| 제목 | 제목 (머리말 제거) |
| 시간 지정 일정 | 시작 날짜·시각 (한국 시간 기준) |
| 종일 일정 | 시각 없이 날짜만 |
| 여러 날 종일 일정 | 날짜마다 하나씩 표시 (최대 14일), 설명 맨 앞에 `기간: 3/12(목) ~ 3/14(토)` 추가 |
| 위치 | 장소 |
| 설명 | 상세 설명 (서식은 빼고 글자·줄바꿈만 표시) |
| 첨부 파일 | 첫 번째 첨부가 "세션 자료 PDF" 버튼이 됨. 첨부가 없으면 설명 안의 구글 드라이브/문서 링크나 `.pdf` 링크 중 첫 번째를 사용 |

## 사진 갤러리 (구글 드라이브)

홈의 사진 갤러리는 동아리 구글 드라이브의 **`Gallery` 폴더**(ID `1ePToGxtANGVHkGJ0yWgnOw9D_vUTrS3o`)를 그대로 보여줍니다. 사진은 드라이브 폴더에 올리기만 하면 되고, 코드나 `index.html`을 고칠 필요가 없습니다.

동작 방식

1. 브라우저가 `/api/gallery`(`api/gallery.js`)를 부릅니다.
2. 이 함수가 Google Drive API로 폴더 안의 사진 목록을 읽어 날짜·설명을 붙이고 **최신 날짜순**으로 돌려줍니다.
3. 결과는 Vercel에서 약 **10분간 캐시**됩니다. 사진을 올리거나 지워도 사이트에 보이기까지 최대 10분 정도 걸릴 수 있습니다.
4. 사진이 1장 이상이면 홈 갤러리의 폴라로이드 4칸을 최신 사진부터 채우고, 누르면 크게 볼 수 있습니다. 5장 이상이면 **더보기**를 눌러 전체 사진을 볼 수 있습니다 (4장 이하면 더보기 버튼은 숨겨짐, 폴라로이드의 남는 칸은 자리표시 그대로).
5. 폴더가 비어 있거나, API 키가 없거나, 구글 쪽 오류가 나면 지금과 같은 자리표시("정기 세션 현장" 등)가 그대로 보입니다.

### 사진 올리는 법

1. 구글 드라이브에서 `Gallery` 폴더를 열고 사진 파일을 **폴더 바로 안에** 올립니다.
   - **하위 폴더 안의 사진은 쓰이지 않습니다.** 이미지 파일(jpg, png, heic 등)만 쓰이고, 휴지통에 넣은 파일은 빠집니다.
   - 폴더가 "링크가 있는 모든 사용자 – 뷰어"로 공유되어 있으므로, 안에 올린 사진도 그 공유 설정을 물려받아 공개됩니다. 사진마다 공유를 따로 제한하면 사이트에서 깨진 이미지(색 칸)로 보이니 그대로 두세요.
   - 폴더에 올린 사진은 **누구나 볼 수 있게 됩니다.** 공개해도 되는 사진만 올리세요.
2. 파일 이름은 **`YYYY-MM-DD_설명.jpg`** 형식을 권장합니다. 예: `2026-03-12_신입환영회.jpg` → 사이트에 "신입환영회 · 2026.3.12"로 표시.

날짜를 정하는 순서

1. 파일 이름 맨 앞의 날짜: `2026-03-12`, `20260312`, `2026.03.12`, `2026_03_12`, `2026 03 12` 모두 가능 (`2026-3-12`처럼 한 자리 월·일도 구분자가 있으면 가능)
2. 없으면 사진의 촬영 시각(EXIF)
3. 그것도 없으면 드라이브에 올린 시각 (한국 시간 기준 날짜)

설명(캡션)을 정하는 순서

1. 드라이브에서 파일 → 세부정보(ⓘ) → **설명**에 적은 글이 있으면 그것
2. 없으면 파일 이름에서 앞의 날짜, 구분자, 확장자를 뺀 부분 (`_`는 공백으로 바뀜, 예: `20260312_KIDA_연합세션.jpg` → "KIDA 연합세션")
3. `IMG_1234.jpg`, `20260312_143022.jpg`처럼 카메라가 붙인 숫자 이름이면 설명 없이 날짜만 표시

사진 설명은 영어(EN) 화면에서도 번역하지 않고 그대로 보입니다.

### 필요한 설정

- `GOOGLE_API_KEY`(달력과 같은 키)의 Google Cloud 프로젝트에서 **Google Drive API를 사용 설정**해야 합니다. 키에 API 제한을 걸었다면 Drive API도 허용 목록에 넣으세요.
- 다른 폴더를 쓰려면 Vercel 환경 변수 `GDRIVE_FOLDER_ID`에 폴더 ID(폴더 주소 `drive.google.com/drive/folders/<ID>`의 마지막 부분)를 넣습니다. 생략하면 위 `Gallery` 폴더를 씁니다.
- 환경 변수를 바꾼 뒤에는 **다시 배포해야** 적용됩니다.

## 방명록 수정하기

이 페이지는 원래 Claude 아티팩트로 게시되어, 운영진이 화면에서 바로 방명록을 고칠 수 있었습니다. Claude 아티팩트 런타임에 대한 의존성을 없애면서 **방명록은 읽기 전용**이 되었고, 화면에는 입력 창이 없습니다.

데이터는 `index.html` 안에 들어 있는 JSON 블록에서 읽어옵니다. (`cal-data` 블록도 같은 방식이지만, 위에서 설명한 것처럼 지금은 구글 캘린더를 불러오지 못할 때만 쓰입니다.)

```html
<script type="application/json" id="gb-data">[ ...방명록 목록... ]</script>
<script type="application/json" id="cal-data">[ ...예비 일정 목록... ]</script>
```

수정 순서

1. `index.html`에서 `id="gb-data"` 블록을 찾아 JSON 배열을 고칩니다.
2. 커밋하고 `main`에 push합니다.
3. Vercel이 자동으로 다시 배포합니다.

주의할 점

- 반드시 올바른 JSON이어야 합니다 (큰따옴표, 마지막 항목 뒤 쉼표 없음). JSON이 깨지면 오류 없이 **빈 방명록**으로 표시됩니다.
- 문자열 안에 `<` 문자를 쓰려면 `<`로 적어야 합니다. 그대로 쓰면 `</script>` 같은 내용이 블록을 끝내버릴 수 있습니다.
- 모든 텍스트는 HTML이 아니라 일반 글자로 표시됩니다 (태그를 넣어도 적용되지 않음).

### 예비 일정 형식 (`cal-data`, 참고용)

구글 캘린더 API의 응답(`/api/calendar`의 `events`)도 같은 형식입니다.

```json
[
  {
    "id": "e2026-10-07",
    "title": "정기 세션 (BP)",
    "date": "2026-10-07",
    "time": "18:30",
    "type": "session",
    "place": "310관 B501",
    "desc": "모션: THW ban smartphones in schools",
    "pdf": "https://drive.google.com/..."
  }
]
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 선택 | 일정마다 다른 값. 없으면 자동으로 만들어짐 |
| `title` | 필수 | 일정 제목 |
| `date` | 필수 | `"YYYY-MM-DD"` 형식 (예: `"2026-10-07"`, 월·일은 두 자리) |
| `time` | 선택 | `"HH:MM"` 24시간 형식 (예: `"18:30"`). 같은 날 일정은 시간순 정렬, 시간이 없으면 뒤로 감 |
| `type` | 선택 | `session`(세션) · `tour`(대회) · `event`(행사) · `joint`(연합) · `etc`(기타) 중 하나. 그 외 값이나 생략 시 `etc` |
| `place` | 선택 | 장소 |
| `desc` | 선택 | 상세 설명 (일정 상세 창에 표시) |
| `pdf` | 선택 | 세션 자료 링크. `http://` 또는 `https://`로 시작해야 하며, 아니면 버튼이 표시되지 않음 |

### 방명록 (`gb-data`)

```json
[
  {
    "id": "g1",
    "name": "홍길동",
    "from": "부산, 대한민국",
    "who": "25학번 영문과",
    "msg": "CUDS 최고!",
    "color": "blue",
    "at": "2026.10.5",
    "x": 845.2,
    "y": 160.4
  }
]
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 항목마다 다른 값 (영문·숫자 권장, 따옴표 금지). 지도 핀과 엽서 카드를 연결하는 데 쓰임 |
| `name` | 필수 | 이름 또는 닉네임 |
| `from` | 필수 | 출신 지역 |
| `who` | 선택 | 기수·학과 등 |
| `msg` | 필수 | 한마디 |
| `color` | 선택 | `blue` · `pink` · `orange` · `green` · `lilac` · `yellow` 중 하나. 그 외 값이나 생략 시 `blue` |
| `at` | 선택 | 날짜 문자열, 관례상 `"YYYY.M.D"` (예: `"2026.10.5"`, 앞자리 0 없음) |
| `x`, `y` | 필수 | 지도 위 핀 위치. 세계지도 SVG의 `viewBox="0 0 1000 394.44"` 좌표 (x: 0~1000, y: 0~394.44, 왼쪽 위가 원점) |

좌표 찾는 법: 사이트의 방명록 페이지에서 개발자 도구 콘솔을 열고 아래 코드를 붙여넣은 뒤 지도를 클릭하면 해당 위치의 좌표가 출력됩니다.

```js
document.getElementById("mapSvg").addEventListener("click", function (ev) {
  var p = this.createSVGPoint(); p.x = ev.clientX; p.y = ev.clientY;
  var q = p.matrixTransform(this.getScreenCTM().inverse());
  console.log(Math.round(q.x * 10) / 10, Math.round(q.y * 10) / 10);
});
```
